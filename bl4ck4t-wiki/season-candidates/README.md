# Season Candidate Backlog

This directory stores private future-season candidate briefs. These pages help compare large cybersecurity stories before one is selected for the full source-first season workflow.

Season 5 remains selected as [The Love Letter Plague](../seasons/season-05-the-love-letter-plague.md), anchored on ILOVEYOU / The Love Bug. The candidates below are future options, not replacements for Season 5.

## Candidate Pages

- [WannaCry Ransomware](wannacry-ransomware.md) - ransomware, patch debt, recovery, and public-service disruption.
- [Log4Shell](log4shell.md) - hidden dependencies, software inventory, emergency patching, and long-tail exposure.
- [Colonial Pipeline / DarkSide](colonial-pipeline-darkside.md) - ransomware economics, critical infrastructure, operational disruption, and public panic.
- [MOVEit / CL0P](moveit-cl0p.md) - managed file transfer, third-party risk, data extortion, and notification discipline.

## Use Rule

Selecting a candidate does not bypass the required historical process. A selected candidate still needs:

- real-world source page;
- sourced historical account;
- historical documentary treatment;
- BL4CK4T-world import pass;
- support canon pages;
- production bible;
- mission packets;
- private drafts;
- draft review and continuity audit;
- release historical-anchor analysis;
- public season page and episode posts;
- TROPES, wiki, and build validation.

# Public Private Cryptography

## Summary

Public/private cryptography uses paired keys so one key can be shared while the other remains secret. BL4CK4T currently explains it with the mailbox analogy.

## BL4CK4T Teaching Frame

Use key pairs to make identity, signatures, encryption, and trust visible through doors, seals, and city keys.

## Story Hooks

- City mailboxes.
- Locked gates with public slots.
- Signatures that prove a message came from the right sender.

# File Appearance Deception

## Summary

File appearance deception happens when a file's name, icon, or presentation makes it look safer or simpler than its behavior. Season 5 uses fictional letter seals and hidden endings to teach the concept.

## BL4CK4T Teaching Frame

- A friendly name does not prove safe behavior.
- File appearance and file action can differ.
- Safe review happens in approved tools and spaces.
- When unsure, ask and report.

## Story Hooks

- Cipher notices the Glitter Letter has a hidden ending.
- Byte builds a display that shows appearance and behavior as separate cards.
- The city learns not to judge a message by the prettiest seal.

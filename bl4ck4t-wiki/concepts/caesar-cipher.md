# Caesar Cipher

## Summary

A Caesar cipher shifts each letter by a fixed number of positions. In BL4CK4T, it is the first puzzle that teaches pattern spotting and verification.

## BL4CK4T Teaching Frame

Use Caesar ciphers as a beginner-friendly way to show that secret writing follows rules and that a key changes how a message is read.

## Story Hooks

- Ancient code in neon form.
- Shifted billboard messages.
- First step before stronger cryptography.

# Attachment Trust

## Summary

Attachment trust is the habit of deciding whether a file is safe based on sender, context, file appearance, and expected behavior before opening it.

## BL4CK4T Teaching Frame

- Pause before opening unexpected attachments.
- Verify sender and context through a separate path.
- Treat urgency, affection, and surprise as reasons to slow down.
- Report suspicious messages instead of forwarding them.

## Story Hooks

- Pixel wants to inspect a glittering letter but waits for the Quarantine Tray.
- Jinx asks whether the message was expected before asking who sent it.
- Whiskers writes a city warning that avoids shaming anyone who clicked.

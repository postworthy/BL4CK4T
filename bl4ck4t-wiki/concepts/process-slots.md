# Process Slots

## Summary

Process slots are the limited places inside a simulator, terminal, or learning room where running tasks can occupy system attention.

In Season 3, the Copycat Sprite does not need to destroy files to cause harm. Extra copies occupy process slots, increase counter pressure, and delay ordinary class tools.

## BL4CK4T Teaching Frame

Process slots make the Morris Worm's non-destructive impact easier to understand. A system can fail because too many processes are running, not because the data is gone.

## Story Hooks

- The ninth marker represents an extra process slot occupied outside Byte's plan.
- Slow rooms happen when extra sprite copies hold process slots that class tools need.
- Clearing rooms means freeing slots and verifying that normal tasks can run again.

## Public Boundary

Do not describe real process manipulation, exploit paths, or worm implementation. Keep the concept at the level of limited system capacity and defender observation.

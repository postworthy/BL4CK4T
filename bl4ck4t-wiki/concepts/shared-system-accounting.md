# Shared-System Accounting

## Summary

Shared-system accounting tracks how common resources are used: compute time, storage, reservations, print jobs, lab credits, or access windows. It helps caretakers understand fair use, capacity, and anomalies.

## BL4CK4T Teaching Frame

- Accounting records can be security clues.
- Small mismatches should be checked before they are dismissed.
- Most mismatches are ordinary, so investigators must learn normal noise.
- Accounting records become stronger when compared with other evidence.

## Season 2 Use

The `-0.75` mismatch matters because it appears in a shared resource ledger. Jinx has to learn what normal Ledger Lab noise looks like before she can prove the mismatch is unusual.

## Story Hooks

- A storage credit that vanishes while a project is closed.
- A print job charged to the wrong lab table.
- Pixel realizing that boring math is how the system tells on itself.

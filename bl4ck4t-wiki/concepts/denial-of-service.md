# Denial Of Service

## Summary

Denial of service is an availability problem where a system is made unable to answer legitimate users reliably. In BL4CK4T stories, it is represented through fictional request floods and blocked civic doors, not real techniques.

## BL4CK4T Teaching Frame

- Nothing has to be stolen for harm to occur.
- Repeated requests can crowd out legitimate users.
- Defenders respond with prioritization, filtering, redundancy, fallback paths, and communication.
- Attribution should stay separate from claims and rumors.

## Story Hooks

- Empty delivery receipts ask the same harmless question too many times.
- Pixel realizes that repeated blankness can be evidence.
- Cipher separates `who claimed it` from `what the evidence supports`.

# Season 7 Episode 5: The Repair Lane

## Summary

Byte and Jinx build a verified path for urgent City Runtime updates so citizens can distinguish real repair from imitation.

## Featured Characters

- Byte makes repair tooling concrete.
- Jinx demands source, signature, owner, rollback, status, and verification.

## Lesson Payload

- Concept: [Verified Updates](../concepts/verified-updates.md).
- Defensive takeaway: urgency does not replace proof.
- Teacher note: a trusted update path is part of the repair.

Two repair notices reach the library at once: one verified, one only loud.

# Patch Phantom

## Summary

Patch Phantom haunts forgotten systems in The Old Stack. It slips through old doors, faded lock plates, and machines everyone meant to fix later.

## Public Motif

- Flickering patches.
- Dusty service doors.
- Footprints that appear only under maintenance light.
- Old warning labels curling at the edges.

## Personality

Patient, quiet, and opportunistic. Patch Phantom does not need a clever trick if a neglected door remains open.

## Inspiration Class

Known exploited vulnerabilities, delayed patching, asset inventory, ransomware prevention, and maintenance failures.

## Safe Tactic Abstraction

Patch Phantom moves through fictional city doors that still use old locks. The story focus is finding, updating, and verifying those doors.

## Defensive Lesson Mapping

- Keep an inventory.
- Patch exposed systems.
- Verify important updates.
- Keep backups.
- Segment systems so one failure does not become every failure.

## Episode Hooks

- A classroom lab keeps relocking its own files because one old service door was missed.
- Grimalkin maps The Old Stack and finds an unpatched tunnel on every route.
- Byte's simulator proves that one fixed door is not enough if the city map is incomplete.

## BL4CK4T Transformation

A self-copying message sprite created for a lab keeps multiplying through old city tunnels. The conflict is not evil intent; it is uncontrolled spread.

## Season Theme

- Technical theme: propagation, containment, and incident response.
- Character theme: Byte learns that working code is not the same as safe code.
- Ethical theme: intent does not erase impact.

## Core Lessons

- Test safely.
- Contain experiments.
- Connected systems amplify mistakes.
- Response and accountability matter.

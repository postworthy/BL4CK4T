# Hidden Code Lesson

## Summary

The first BL4CK4T lesson teaches learners to recognize and solve a Caesar cipher through pattern spotting, shift testing, teamwork, and verification.

## Teaching Payload

- Concept: Caesar cipher / shift cipher.
- Beginner hook: strange letters that look like gibberish but preserve word spacing.
- Activity: test shifts until readable plaintext appears.
- Example: shift five transforms the message into "THIS IS A TEST FOR A NEW ADVENTURE."
- Takeaway: simple codes are a gateway to deeper cryptography and security thinking.

## Story Use

Use this lesson when introducing puzzle-solving, first contact with BL4CK4T, or the difference between obscurity and stronger cryptography.

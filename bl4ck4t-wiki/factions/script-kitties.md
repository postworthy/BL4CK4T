# Script Kitties

## Summary

The Script Kitties are a learner crew guided by BL4CK4T. They are not an offensive hacking group; they are a curiosity-first team learning how systems work so they can help and defend.

## Ethos

- Learn by doing.
- Verify before trusting.
- Share discoveries responsibly.
- Use skills with consent.
- Defend first.

## Published Season Canon

- Pilot: forms around BL4CK4T's lesson drops.
- Season 1: learns that hidden system rules create responsibility.
- Season 2: learns that evidence must be preserved before it can persuade others.
- Season 3: learns that builders must plan for failure, containment, and recovery.

## Operating Pattern

The team works best when Pixel notices, Jinx questions, Cipher verifies, Byte builds, Shadow observes, Grimalkin coordinates, and Whiskers keeps the mission centered on people.

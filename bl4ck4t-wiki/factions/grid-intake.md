# Grid Intake

## Summary

Grid Intake is a Glass Bureau-facing desk that handles Civic Learning Grid reports before ownership is clear.

## Story Use

Use Grid Intake for the first handoff when a problem crosses the Grid but no department yet owns the whole case.

## Canon Notes

- Grid Intake should feel process-heavy, not useless.
- It can route reports badly when the report lacks scope or requested action.

# Public Terminals

## Summary

Public Terminals is the civic desk responsible for terminals used by the public across libraries, museums, and learning spaces.

## Story Use

Use Public Terminals when a case involves shared machines outside a single lab.

## Canon Notes

- Public Terminals does not own every endpoint's local context.
- It should coordinate with Library Systems and Museum Systems.

## Usage Rules

- Character-card hoodie colors are now visual canon for the Script Kitties.
- Do not overwrite the BL4CK4T logo silhouette without explicit approval; it is already used for stickers.
- Future generated art should preserve the neon cyberpunk palette, dark feline base forms, hoodie-color identity, and city-sign storytelling language described in [Visual Style Guide](../style-guides/visual-style-guide.md).

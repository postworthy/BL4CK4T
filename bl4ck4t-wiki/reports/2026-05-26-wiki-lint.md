# 2026-05-26 Wiki Lint Report

## Summary

The BL4CK4T wiki is structurally healthy for its current stage. `pnpm wiki:check` passed, all index links resolve, and all non-template wiki pages are indexed. The main work now is not link repair; it is canon maturity, provenance depth, and story-production readiness.

## Checks Run

- `pnpm wiki:check` - passed.
- File length review - no empty or stub-only pages, but several pages remain intentionally thin.
- Index coverage review - every non-template page except `index.md` and `log.md` is represented in the index.
- Seed/draft scan - multiple pages still have `status: seed` or `status: draft`.
- Local link scan - no missing local markdown links found by the checker.
- Source URL spot check - Nmap and History.com responded with HTTP 200. CISA pages were discoverable through search but returned HTTP 403 to direct `curl` from this environment, likely bot protection rather than a content issue.

## Highest-Priority Attention Areas

### 1. Character Backstories

Every individual Script Kitty page still has `status: seed` and a `Backstory Seeds` section. These are usable for voice, but not yet strong enough for sustained multi-episode arcs.

Recommended next work:

- Decide one formative event per Script Kitty.
- Add a "Wants / Fears / Growth Edge" section to each character.
- Promote character pages to `status: active` only after those details are stable.

### 2. BL4CK4T Identity

[BL4CK4T](../characters/bl4ck4t.md) still has unresolved open questions about whether BL4CK4T is a person, collective, AI, legend, or something else. This is a high-impact decision because it shapes every future drop.

Recommended next work:

- Keep BL4CK4T mysterious publicly.
- Decide an internal answer or define an intentional "mystery box" policy.
- Add clear limits on what BL4CK4T can and cannot do.

### 3. Locations Need More Story Utility

[Cybertropolis](../locations/cybertropolis.md) has useful districts, but [The Hideout](../locations/the-hideout.md) is still thin. Locations need sensory details and repeatable story functions.

Recommended next work:

- Add district-specific recurring props, hazards, and lesson mappings.
- Expand The Hideout into zones: terminal wall, whiteboard, repair bench, roof access, and quiet corner.
- Add location-to-lesson routing notes.

### 4. Villain Roster Is Started, Not Yet Deep

The first three villains are active, but only [The Phishmonger](../villains/the-phishmonger.md) has a mission and draft attached. [Patch Phantom](../villains/patch-phantom.md) and [Supply Serpent](../villains/supply-serpent.md) need mission packets before they become story-ready.

Recommended next work:

- Create `missions/patch-phantom-old-stack.md`.
- Create `missions/supply-serpent-packet-market.md`.
- Add "Recurring Defeat Pattern" to each active villain so they can return without repeating the exact same lesson.

### 5. Real-World Source Provenance Needs More Depth

The real-world source pages are intentionally high-level and safe, but they currently summarize from a small source set. This is enough for seed story work, not enough for teacher-grade background.

Recommended next work:

- Add at least one additional authoritative source per real-world topic.
- Prefer CISA, FBI, NIST, OWASP, Nmap official docs, MITRE ATT&CK high-level pages, or vendor-neutral education sources.
- Add "Teacher-Facing Notes" only where the public story needs more technical context.

### 6. Lesson Pages Need Classroom Shape

The lesson pages currently preserve the lesson payload from stories, but they do not yet provide a repeatable teacher workflow.

Recommended next work:

- Add `Objective`, `Activity`, `Discussion Questions`, `Safe Lab Option`, and `Assessment Prompt` sections to each lesson page.
- Start with [Hidden Code Lesson](../lessons/hidden-code-lesson.md), [Keys To The City Lesson](../lessons/keys-to-the-city-lesson.md), and the Phishmonger/phishing lesson.

### 7. First Draft Needs Promotion Review

[The Phishmonger On Signal Row](../drafts/phishmonger-signal-row.md) is structurally complete and safety-conscious, but it should receive a style and canon review before public publication.

Recommended next work:

- Decide whether the public post should use the current draft title.
- Decide whether The Phishmonger should be introduced in the public blog now or after more character backstory is developed.
- Choose or generate a dedicated card image instead of reusing `script-kitties-crowd.jpg`.

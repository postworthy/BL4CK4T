# OWASP Juice Shop

## Summary

OWASP Juice Shop is an intentionally vulnerable web application used for security training. In BL4CK4T, it represents the right pattern for practice: use a safe lab designed for learning.

## Defensive Lesson

- Practice should happen in intentionally vulnerable labs.
- Web-security lessons need consent and boundaries.
- Finding a weakness should lead to understanding and repair.

## Unsafe Details To Avoid Publicly

- Do not point learners at real websites for testing.
- Avoid exploit walkthroughs outside a clearly bounded lab context.

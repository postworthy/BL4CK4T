# Script Kitties Episode 1: The Hidden Code

## Summary

The pilot episode introduces Cybertropolis, the Script Kitties, BL4CK4T's encrypted drops, and the team's first lesson: a Caesar cipher shifted by five.

## Canon Contributions

- Cybertropolis is a neon city with steel towers, glowing data streams, alleys, rooftops, and billboard-style signals.
- The Script Kitties are Grimalkin, Pixel, Byte, Whiskers, Cipher, Jinx, and Shadow.
- The team has a warehouse hideout with old servers, wires, a terminal, and whiteboard-style learning space.
- BL4CK4T sends a message marked by a pawprint logo.
- Cipher is the codebreaker.
- Pixel is curious and physically expressive.
- Byte uses terminals and tools.
- Whiskers acts as a leader.
- BL4CK4T's closing message points toward public/private keys and future lessons.

## Lesson Contributions

- Caesar ciphers shift letters by a fixed number.
- Trial and error can reveal the correct shift.
- Verification matters after a solution appears.
- Simple ciphers can introduce larger security concepts.

# ClassOverride Project Page

## Summary

The ClassOverride project page describes an open-source teaching repo for teenage learners. It uses BL4CK4T drop flavor and notebook-first labs to teach hacker mindset topics.

## Canon Contributions

- "ClassOverride" is a BL4CK4T-aligned curriculum/lab concept.
- BL4CK4T drops can frame lab arcs.
- The ethos is "learn, help, defend."
- Labs should embed ethics, consent boundaries, and defend-first habits.

## Curriculum Signals

- Cryptography starters: Caesar, frequency analysis, Diffie-Hellman, toy RSA, hybrid crypto.
- Compound-interest and frugality labs.
- Adversarial prompt evolution for classroom discussion.
- Wargames-style exercises in safe scenarios.
- Nmap host discovery and service enumeration.
- OWASP Juice Shop and guided fixes.

# Signal Row

## Summary

Signal Row is the neon communications district where Season 1 unfolds. It contains billboards, antenna towers, message kiosks, public alerts, rooftop relays, transit notices, and old Echo Grid infrastructure.

## Story Use

Use Signal Row for stories about public messages, trusted alerts, signal architecture, rumor spread, and civic communication.

## Visual Motifs

- Neon signs.
- Antenna towers.
- Message kiosks.
- Rooftop relays.
- Transit boards.
- Listener marks and stickers.

## Canon Notes

- The Echo Grid and Hushline are Signal Row-specific Season 1 canon.
- The Hushline successfully fixes the message-command ambiguity.
- Row Rebels and Rook are tied to this district.

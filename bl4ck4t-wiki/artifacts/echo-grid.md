# Echo Grid

## Published Canon

The Echo Grid is an old Signal Row signal layer where civic messages and routing instructions once shared the same stream. Pixel hears its three-note phrase first, Shadow notices physical beacon responses, and the Script Kitties map it across old kiosks, relays, and listener marks.

## Story Function

- Season 1 mystery engine.
- Transforms in-band signaling into a fictional city architecture.
- Teaches that hidden rules can be discovered, but discovery creates responsibility.

## Current State

The Echo Grid's message-command ambiguity is resolved for Signal Row by the Hushline. Future stories should not simply undo that fix.

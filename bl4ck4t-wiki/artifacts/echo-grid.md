# Echo Grid

## Published Canon

The Echo Grid is an old Signal Row civic communications network where public service messages and routing instructions once shared the same signal stream. Pixel hears its three-note phrase first, Shadow notices physical beacon responses, and the Script Kitties map it across old kiosks, relays, cabinet paths, listener marks, and system responses.

## Story Function

- Season 1 mystery engine.
- Transforms in-band signaling into a fictional city architecture.
- Establishes the reusable message-command separation lesson.
- Teaches that hidden rules can be discovered, but discovery creates responsibility.

## Current State

The Echo Grid's message-command ambiguity is resolved for Signal Row by the Hushline. Future stories should not simply undo that fix.

## Technical Texture Notes

- Safe terms for future references: communications network, public service message, routing instruction, signal stream, relay, cabinet, kiosk, system response, maintenance path.
- The Echo Grid should never be treated as a magic song system alone. It is a public communications network with an old design flaw.
- The core flaw is architectural ambiguity: user-facing messages and control/routing instructions traveled through a shared path.

# Tonebox

## Published Canon

The Tonebox is Byte and Pixel's Season 1 model that makes Echo Grid behavior visible. Its danger is social: a clear demo can become a shortcut, status object, or misunderstood tool when removed from its lesson.

## Story Function

- Teaches that packaging knowledge changes how people use it.
- Starts Byte's longer arc from impressive demos toward responsible engineering.

## Current State

Covered after the false closure incident. Future Byte tools should remember the Tonebox lesson.

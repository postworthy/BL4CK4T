# Tonebox

## Published Canon

The Tonebox is Byte and Pixel's Season 1 non-operational model that makes Echo Grid behavior visible. It shows a shared message-command path, then a separated Hushline path. Its danger is social: a clear demo can become a shortcut, status object, or misunderstood tool when removed from its lesson.

## Story Function

- Teaches that packaging knowledge changes how people use it.
- Models a trust boundary without acting as a real controller.
- Starts Byte's longer arc from impressive demos toward responsible engineering.

## Current State

Covered after the false closure incident. Future Byte tools should remember the Tonebox lesson.

## Technical Texture Notes

- Safe terms for future references: model, concept demo, trust boundary, message path, command path, route label, cabinet number, controller.
- The Tonebox should be described as stripped of real route names, real cabinet identifiers, and real control capability.
- It can explain why a system failed, but it should not be portrayed as a working tool for touching city infrastructure.

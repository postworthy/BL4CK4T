# Crunch Charm

## Published Canon

The Crunch Charm is the public myth object that grows out of the Little Blue Pawprint rumor. It is easier for Signal Row kids to talk about than the deeper Echo Grid architecture, but it has no permission, account, authorization, or command power of its own.

## Story Function

- Mirrors whistle mythology without copying real-world details.
- Shows how a symbol can distract from a system flaw.

## Current State

The charm remains a myth object, not a magic key. Future stories should preserve that distinction.

## Technical Texture Notes

- Safe terms for future references: myth object, permission, account, authorization, ambiguous signal, command path.
- The charm does not authenticate or authorize anything.
- Its story function is to show how a visible object can distract from an architectural trust problem.

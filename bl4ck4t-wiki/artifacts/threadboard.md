# Threadboard

## Published Canon

The Threadboard is Byte and Jinx's Season 2 evidence wall. It records, orders, compares, and visualizes records without changing the scene. It begins with the `-0.75` clues, Project Orchard records, terminal warmth, print slips, and timing cards.

## Story Function

- Makes defensive investigation tactile.
- Gives Jinx a place to separate suspicion from evidence.
- Gives Byte a tool that preserves truth rather than forcing an answer.

## Current State

Copied as a caretaker tool after Season 2. It can recur as an evidence-control pattern.

# Hushline

## Published Canon

The Hushline is the Season 1 architectural fix created with Mira. It separates public message paths from routing-command and control paths so Signal Row can keep singing without treating every song as an order.

## Story Function

- Turns the season's technical lesson into visible repair.
- Establishes that durable fixes are often architectural.
- Gives future stories a clear example of separated control paths.
- Provides the `-0.75` clue that launches Season 2.

## Current State

Successful Season 1 outcome. The Hushline may surface as a model, reference, or inherited lesson, but future conflict should not cheapen its success.

## Technical Texture Notes

- Safe terms for future references: separated control path, service path, routing command, public message path, maintenance node.
- The Hushline represents architectural separation, not merely a nicer version of the Echo Grid.
- Future stories can reuse the Hushline as a teaching example for trust boundaries, but should not reopen the same Signal Row flaw without explicit continuity revision.
